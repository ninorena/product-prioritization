# Jobs to be done

Each test names the number of the job it proves. The words are defined here:

- **Note:** one sticky note. A note holds one question about the product.
- **Board:** one 2x2. The vertical axis goes from Less Important to More Important. The horizontal axis goes from Harder to Easier.
- **Own board:** the board that one person fills in alone.
- **Round:** one pass through the steps, from brainstorm to vote.

| # | When | I want to | So that |
|---|---|---|---|
| 2 | We start a brainstorm | see prompts about what can make the product fail | I think about risks |
| 3 | A question comes to mind in the brainstorm | write it as a note on the canvas at once | each note can help define one specific experiment |
| 4 | I have questions on a notepad | type them into the tool, one note after the other | I can think in a different place and still use the tool |
| 5 | The notes are final | place each note on my own board, alone | other people do not change my first opinion |
| 6 | All the own boards are full | compare them one time, live or async | I see where we disagree before I change my board |
| 7 | Two notes feel equally important in a live talk | ask which one we know less about | we experiment on the more uncertain one |
| 8 | I place a note between Harder and Easier | think about how hard the question is to answer | we find the questions that we must answer first |
| 9 | The compare step is done | vote with the group | we pick one question together |
| 10 | We decide what to do with a note | move it off the board to icebox, in progress, or closed | the board stays in use for the full project |
| 11 | Many notes are about one topic | put them in a cluster or merge them | we can decide on a topic, not only on one note |
| 12 | A round is done | export the result as a PDF | I can add it to a report |

Version 1 does not merge two notes (job 11). It gives notes a topic label instead.

Version 2 removes job 1. People write questions down on their own, out of the tool. Job numbers do not change.

The method comes from [Completing a 2x2 risk prioritization matrix](https://kromatic.com/blog/completing-a-2x2-risk-prioritization-matrix/).
